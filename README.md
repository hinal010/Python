### 🏧 atm_encapsulation.py

This Python file demonstrates the concept of **Encapsulation in Object-Oriented Programming (OOP)** using an ATM simulation program.

### 📌 What this program does:
- Simulates basic ATM functionality
- Uses a class to protect sensitive data (like account balance)
- Allows secure access through methods only
- Performs banking operations like:
  - Check balance
  - Deposit money
  - Withdraw money

### 🔐 Concept Used:
- Encapsulation (data hiding using private variables)
- Classes and Objects
- Methods for controlled access to data

### 🚀 Purpose:
This program helps understand how real-world banking systems protect user data and allow access only through secure methods.
